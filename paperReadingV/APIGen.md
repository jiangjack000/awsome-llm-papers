 **APIGen**，一个用于生成可验证和多样化函数调用数据集的自动化数据生成框架。APIGen 旨在为函数调用代理模型提供高质量的数据支持，并通过严格的验证流程和多样化策略生成可靠的数据集。以下是文章的核心内容总结：

---

### **研究背景**
函数调用代理模型的发展需要多样化、可靠且高质量的数据集支持。现有的数据集往往存在质量参差不齐或缺乏多样性的问题，限制了模型的性能提升。为此，作者提出了 APIGen，一个自动化生成可验证、多样化函数调用数据集的框架。

---

### **APIGen 框架设计**
APIGen 的设计围绕三个关键因素：**数据质量**、**数据多样性** 和 **可扩展性**。框架通过以下模块实现这些目标：

1. **多阶段数据验证**：通过格式检查、实际函数执行和语义验证三个层级确保数据的可靠性和正确性。
2. **多样化策略**：通过种子问答数据采样器、API 采样器和多种提示模板确保数据多样性。
3. **模块化设计**：采用统一的 JSON 格式，支持多种 API 来源（如 Python 函数和 REST API），便于扩展。

---

### **数据生成流程**
APIGen 的数据生成过程如下：

1. **API 和问答对采样**：从库中采样 API 和示例问答对，并格式化为标准化的 JSON 格式。
2. **提示模板选择**：根据目标选择合适的提示模板，引导语言模型生成相关的问答对。每个答案是一个 JSON 格式的函数调用。
3. **多阶段验证**：
   - **格式检查**：验证 JSON 格式和解析能力，排除格式错误或不完整的数据。
   - **执行检查**：对格式正确的函数调用进行实际执行，排除无法执行的调用。
   - **语义检查**：通过另一个语言模型验证执行结果是否与查询目标一致。
4. **数据回流**：通过验证的数据被添加回种子数据集，用于增强未来数据生成的多样性。

---

### **多样化策略**
APIGen 通过以下方式提升数据多样性：
1. **查询风格多样化**：数据集分为简单、多步、并行和并行多步等类别，覆盖不同使用场景。
2. **采样多样化**：随机选择 API 和示例数量，避免重复模式，确保广泛覆盖。
3. **API 多样化**：从多个来源收集 API，包括 ToolBench 和 Python 函数。

---

### **数据集细节**
1. **API 来源**：主要从 ToolBench 收集，包含 16,464 个 REST API，覆盖 49 个类别。经过过滤和清理后，最终保留了 3,539 个可执行的 REST API 和 134 个 Python 函数。
2. **数据生成**：使用多个基础语言模型（如 DeepSeek-V2-Chat 和 Mixtral）生成数据，目标是生成 40,000 个数据点。
3. **验证统计**：通过多阶段验证过滤低质量数据，最终生成约 60,000 个高质量数据点。

---

### **实验结果**
1. **性能表现**：
   - 使用 APIGen 数据集训练的 7B 参数模型在 Berkeley 函数调用基准测试中达到了 88.24% 的准确率，超越了多个 GPT-4 模型。
   - 1B 参数模型也表现出色，准确率达到 78.94%，超越了 GPT-3.5-Turbo 和 Claude-3 Haiku。
2. **数据集发布**：作者发布了包含 60,000 个高质量数据点的数据集，涵盖 21 个类别的 3,673 个 API，旨在推动函数调用代理领域的研究。

---

### **结论**
APIGen 通过严格的多阶段验证和多样化策略，成功生成了高质量、多样化的函数调用数据集。这些数据集显著提升了函数调用代理模型的性能，即使在较小的模型规模下也能达到优异的效果。APIGen 的设计和实现为函数调用代理模型的研究提供了重要的支持和参考。

---

1. 提出了一个自动化生成高质量、多样化函数调用数据集的框架。
2. 通过多阶段验证确保数据的可靠性和正确性。
3. 在多个基准测试中验证了数据集的有效性，展示了其对模型性能的显著提升。
4. 公开发布了高质量的数据集，推动该领域的研究发展。
