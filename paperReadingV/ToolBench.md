ToolBench 是一个开源平台，旨在为训练、服务和评估大型语言模型（LLM）在工具学习（tool learning）方面的能力提供支持。它通过收集高质量的指令调整（instruction-tuning）数据集，帮助开源 LLM 掌握数千种真实世界的 API。以下是该平台的核心内容总结：

---

### **ToolBench 项目简介**
ToolBench 是一个专注于工具学习的开源平台，目标是构建一个大规模、高质量的指令调整数据集，以促进开源 LLM 在工具使用方面的能力提升。它通过自动收集和筛选数据，为 LLM 提供丰富的工具使用场景，支持单工具和多工具场景，并提供详细的推理过程和工具执行结果。

### **核心功能**
1. **API 收集**：从 RapidAPI 平台收集了 16,464 个 REST API，涵盖多种真实世界工具。
2. **指令生成**：生成涉及单工具和多工具场景的指令，支持复杂任务的推理和规划。
3. **答案标注**：采用基于深度优先搜索的决策树（DFSDT）方法，标注指令的解决方案路径，包含模型的推理过程、工具执行和结果。
4. **API 检索**：整合 API 检索功能，使模型具备开放域工具使用能力。
5. **数据自动化生成**：利用 OpenAI API 自动生成数据，并通过筛选确保数据质量。

### **数据集特点**
- **规模**：包含 3,451 个工具、16,464 个 API 和 126,486 个实例。
- **多样性**：涵盖单工具和多工具场景，支持跨类别和跨集合的多工具任务。
- **质量**：所有数据均通过自动化生成并经过筛选，确保数据的可靠性和可用性。

### **模型与训练**
ToolBench 提供了预训练的 **ToolLLaMA** 模型，该模型在工具使用任务上表现出色，接近 ChatGPT 的性能。此外，还提供了训练和评估脚本，帮助用户复现实验结果。

### **推理与评估**
ToolBench 支持使用预训练模型进行推理，并提供了详细的推理流程。它还开发了 **ToolEval**，一个高效的机器评估器，用于评估模型在工具使用任务上的表现，包括通过率和偏好率两个指标。

### **实验结果**
在实验中，ToolLLaMA 在工具使用任务上表现出色，与 ChatGPT 相当。例如，在单工具场景中，ToolLLaMA 的通过率达到 57%，而在多工具场景中，其通过率可达 66.7%。此外，ToolLLaMA 在偏好率评估中也表现出色，与 ChatGPT 的偏好率相当。

### **资源与扩展**
ToolBench 提供了丰富的工具学习资源，包括 BMTools、工具学习综述论文和相关论文列表。此外，还支持用户自定义 API，方便扩展到新的工具和任务。

### **开源与贡献**
ToolBench 的代码和数据集已开源，用户可以自由使用和贡献。项目还提供了详细的安装、训练和推理指南，帮助用户快速上手。

### **未来展望**
ToolBench 计划在未来进一步提升数据质量和工具覆盖范围，目标是使开源 LLM 在工具使用能力上达到 GPT-4 的水平。

---

### **总结**
ToolBench 是一个强大的开源平台，为 LLM 的工具学习提供了高质量的数据集和评估工具。它通过自动化数据生成和严格的筛选流程，确保了数据的多样性和可靠性，同时提供了高效的模型训练和评估方法。ToolBench 的开源性质和丰富的资源使其成为研究和开发工具学习模型的重要工具。
