- 本文介绍了 Gorilla，一个基于 LLaMA 的微调大型语言模型（LLM），专门用于通过 API 调用工具。尽管当前的 LLM 在自然对话、数学推理和程序合成等任务中表现出色，但它们在通过 API 调用工具时仍存在不足，尤其是在生成准确输入参数和避免错误使用 API方面。Gorilla 通过结合文档检索器，展示了强大的适应能力，能够应对测试时文档的变化，显著减少了直接提示 LLM 时常见的幻觉问题。为了评估模型的能力，作者构建了 APIBench 数据集，涵盖了 HuggingFace、TorchHub 和 TensorHub 的 API。实验结果表明，Gorilla 在 API 功能准确性方面显著优于 GPT-4，并且在减少幻觉错误方面表现出色。
此外，Gorilla 还能够适应 API 档的变化，并在约束条件下进行推理。
Gorilla 的代码、模型、数据和演示可在其官方网站上找到。
